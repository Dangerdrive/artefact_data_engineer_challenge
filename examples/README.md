# Example conversations

These transcripts were generated by running the agent in **offline mode** (deterministic,
no API key needed), so they are fully reproducible:

```bash
python -m src.cli --offline -m "How much is the Takamine GD20?"
python -m src.cli --offline -m "Where is my order? The code is BRAB1234567BR"
```
